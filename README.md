# NumPy & Pandas Practice — Anime Dataset

A beginner-to-intermediate **NumPy and Pandas practice notebook** based on an anime dataset.

## Topics Practiced

- NumPy and Pandas imports
- Reading CSV files
- DataFrame inspection
- Custom functions
- `apply()`
- String extraction and cleaning
- Type conversion
- Data filtering
- `max()`
- `groupby()`
- Sorting

## Files

```text
numpy-pandas-anime-practice/
├── numpy_pandas_anime_practice.ipynb
├── README.md

└── .gitignore
```

## Dataset

The notebook expects a file named:

```text
anime.csv
```

Place it in the same directory as the notebook.

The dataset is intentionally not included here because the original dataset source/license was not provided with the notebook.

## Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Then open the notebook with Jupyter Notebook, JupyterLab, or VS Code.

## Goal

This is a **practice project**, not a full machine-learning project. It is part of my preparation for data analysis and future AI/ML work.
